# Clothing Webshop

In this webshop, you can buy clothing.

## Installation

You can clone my project from the Nexed website.

## Usage

You can buy clothes from my project.

## Features

---

### 1. User Page

- You can see at least 6 items on the User Page.
- You can add clothes to the shopping cart.

---

### 2. Shopping Cart (User)

- You can go back to the User Page.
- You can order the clothes you choose.
- When you click on buy, you get a message that the order is successful.
- You can remove any items you don't need.
- You can clear the whole cart.
- You can choose the amount of clothes you need.

---

### 3. Admin Page

- You can see the order overview: Title, price and name.
- In the order products page, you can see: product Title, product name and price.
- You can see edit and remove buttons.
- You can remove products and the change is visible in both the user page and admin page.
- You can reset products to the original state.

---

#### 4. Adding Product

- You can add a new product: name, price and picture.
- You can preview the picture before adding.
- You can go back to the admin page.
- The new product appears immediately in both user and admin pages.

---

### 5. Editing Product

- You can edit a product: name, price and picture.
- You can preview the picture before saving.
- You can go back to the admin page.
- The changes are visible in both user and admin pages.
